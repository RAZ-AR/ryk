# Handoff: Ryk — Life Experience Companion (прототип 3a)

## Overview
Ryk — мобильное приложение, которое каждую неделю помогает прожить одно настоящее впечатление («историю недели»), а не задачу. Прототип покрывает полный цикл: онбординг → выбор истории → обязательство и приглашение → сопровождение → чек-ин → архив памяти, плюс разделы «Желания» и «Баланс».

## About the Design Files
Файлы в этом бандле — **дизайн-референсы, сделанные в HTML** (прототип, показывающий задуманный вид и поведение), а НЕ продакшн-код для копирования один-в-один. Задача — **воссоздать эти экраны в целевой кодовой базе** её родными паттернами и библиотеками (React Native/Expo, SwiftUI, Flutter и т.д.). Если окружения ещё нет — выбрать подходящий фреймворк (для мобильного приложения логичны React Native/Expo или SwiftUI) и реализовать дизайн там.

Прототип написан как единый компонент состояний экранов: одно состояние `screen` переключает 16 экранов. Слева в HTML есть «навигатор» для перепрыгивания между экранами — **это инструмент прототипа, в продукт не переносится** (только рамка телефона 390×844 переносится как область экрана).

## Fidelity
**High-fidelity (hifi).** Финальные цвета, типографика, отступы и интерактив. Воссоздавать пиксель-в-пиксель средствами кодовой базы. Изображения — плейсхолдеры (`image-slot`), заменяются реальными фото.

## Design Language
- **Тон:** тёплый, человечный, без геймификации. «Обещание, не отчёт», «это не провал — просто погода». Никаких публичных стриков, рейтингов, наказаний.
- **Метафора билета/тикета:** ключевые карточки (идея, кандидат, приглашение) оформлены как отрывной билет — белый верх с фото и заголовком, пунктирная перфорация, два выреза-полукруга по бокам, штрихкод справа.
- **Рукописные подписи** (Caveat) — эмоциональные ремарки, всегда с лёгким поворотом `rotate(-2deg)`, цвет `#D65AA6`.

### Typography (Google Fonts)
- **Golos Text** (400–700) — базовый UI-шрифт.
- **PT Serif** (обычный + italic) — крупные эмоциональные фразы, цитаты.
- **Cormorant** (500/600, italic) — заголовки билетов, `text-transform:uppercase`, `letter-spacing:0.04em`.
- **IBM Plex Mono** (400/500) — служебные метки (класс `.svc`: 10px, `letter-spacing:0.16em`, uppercase), номера, цены/время.
- **Caveat** (500/600) — рукописные подписи.

Крупный logo/числа: `font-weight:700`, отрицательный `letter-spacing` (от -1px до -6px).

### Spacing / Radius / Shadow
- Экран: `padding: 28px 26px`; нижний паддинг **104px** на экранах с доком (чтобы CTA не попадали под dock), онбординг — 26px.
- Рамка телефона: `width:390px; height:844px; border-radius:48px; overflow:hidden`.
- Билет: верх `border-radius:16px 16px 0 0`; фото `border-radius:10px`; тень `0 8px 24px rgba(0,0,0,0.12)`.
- Перфорация билета: `border-top:2px dashed rgba(17,17,17,0.4)`; вырезы — круги 22px цвета фона, смещены `-11px`.
- Штрихкод: `repeating-linear-gradient(90deg,#111 0 2px,transparent 2px 4px,…)`.

## Dock (глобальная навигация)
- Плавающий «островок»: `position:absolute; left:50%; bottom:18px; transform:translateX(-50%)` — **не приклеен к низу**, приподнят на 18px.
- Тёмный: `background:#111; padding:7px; border-radius:22px; box-shadow:0 14px 34px rgba(0,0,0,0.4)`; `max-width:calc(100% - 40px)`.
- 4 пункта-пилюли: **Неделя · Память · Желания · Баланс**. Активный — фон `#F387C8`, текст `#111`; неактивный — прозрачный, текст `#B5B4B1`. Пилюля: `padding:11px 16px; border-radius:16px`, шрифт `.svc` 10px.
- **Показывается на всех экранах, КРОМЕ онбординга** (`welcome`, `categories`, `swipe`, `params`).
- Группировка активности: «Неделя» подсвечена для всей ветки истории (candidate, surprise, commitment, invite, witness, support, rescue, checkin); «Память» → memory; «Желания» → wishlist/addwish; «Баланс» → balance.
- Адаптивность: все функциональные CTA сидят на `margin-top:auto` внутри flex-колонки с нижним запасом 104px, поэтому не перекрываются доком; контент экранов скроллится (`overflow-y:auto`).

## Screens / Views (16)
Все экраны — flex-колонка на всю высоту, служебный хедер сверху (метка слева `#F387C8`, счётчик/× справа), контент, CTA внизу.

1. **welcome** — розовый фон `#F387C8`, гигантский logo RYK (118px), заголовок PT Serif 33px, две CTA: «Начать жить чуть больше» (→ categories) и «У меня уже есть профиль» (→ candidate). *Онбординг, без дока.*
2. **categories** — «Что делает тебя живым?». Сетка 2×4 категорий с рамкой `1px solid #111`, тап переключает выбор (розовая заливка). Счётчик выбранного (Caveat). Назад/Дальше. *Онбординг.*
3. **swipe** — «Пошёл бы?» карточка-билет идеи (15 шт, показаны 3 по кругу). Кнопки «Не моё» / «Хочу это ✓» листают; «Хватит — дальше →» → params. *Онбординг.*
4. **params** — «Твои рамки недели»: бюджет (чипы), с кем (чипы), город+радиус, доля нового 70/30. CTA → candidate. *Онбординг.*
5. **candidate** — «Кандидат N/3», билет-кандидат (фото, день/час, заголовок Cormorant, розовый низ с «Почему/Погода/время·бюджет»). Кнопки «Дальше» (следующий) / «Выбрать» (→ commitment); «Выбери за меня →» → surprise.
6. **surprise** — тёмно-серый экран `#949598`, «Ryk выбрал за тебя», один вариант. CTA → support.
7. **commitment** — «Сделаем это историей недели?»: строки Когда/Бюджет/Компания(→invite)/Свидетель(→witness). CTA «Да, история недели» → support.
8. **invite** — «Позвать Аню/Марка?», билет-приглашение с аватаром-инициалом и личным сообщением (меняется по выбору). Выбор Аня/Марк, «Отправить» (тост → commitment).
9. **witness** — «Сказать кому-то о намерении?» — превью того, что увидит свидетель. Мягкая ответственность, без стриков.
10. **support** — «N дней до субботы», напоминание Ryk, чеклист подготовки (тап циклит статус готово/план/решить). «Не складывается» → rescue, «Событие прошло» → checkin.
11. **rescue** — «План под угрозой», выбор барьера (чипы), 3 варианта спасения (перенести/планетарий/короткая версия) → тост → support; «Пропустить неделю без вины» → memory.
12. **checkin** — «Этот момент теперь твой», Сделано/Перенесено, выбор эмоции, фото (плейсхолдер), одна фраза. → memory.
13. **memory** — «Память · 31», сетка 2×2 карточек-воспоминаний (неделя, название PT Serif, рукописная цитата, компаньон, цветная точка; одна карточка «перенесено» пунктиром). «← Новая неделя» → candidate.
14. **wishlist** — «Wishlist · N», список желаний с тегами/мета; выбранное подсвечено розовым. «+ Добавить желание» → addwish.
15. **addwish** — «Чего хочется?»: текст желания, разбор Ryk (категория/бюджет/когда). «Сохранить» → тост → wishlist (инкрементит счётчики).
16. **balance** — «Баланс», 6 горизонтальных полос категорий с процентами, ремарка + сообщение Ryk про перекос. CTA «Нет, всё ок» / «Да, давай».

## Interactions & Behavior
- **Навигация:** единый `screen`-стейт; переходы мгновенные (без анимации в прототипе — при реализации добавить нативные переходы).
- **Тосты:** `showToast(text, nextScreen)` — показ на 2200 мс внизу над доком (`bottom:96px`), опционально сразу меняет экран.
- **Тап-состояния:** категории/чипы (single или multi select), чеклист (цикл из 3 статусов), выбор кандидата/приглашённого/эмоции/барьера.
- **Билет-по-кругу:** swipe и candidate циклят по массиву из 3.
- **Адаптивность:** контент скроллится под фиксированным доком; CTA прижаты `margin-top:auto`, нижний запас 104px исключает перекрытие доком.

## State Management
Одно состояние на весь прототип:
`screen`, `cats[8]` (bool), `ideaIdx`, `candIdx`, `budget`, `social`, `barrier`, `emotion`, `done`, `invitee` ('anya'|'mark'), `tasks[4]` (0..2), `wishesAdded`, `toast`, `toastTimer`.
Данные (идеи, кандидаты, желания, баланс) заданы массивами-константами в логике — переносятся в модель/фикстуры.

## Assets
Все изображения — плейсхолдеры `image-slot` (id: `pt-idea`, `pt-cand`, `pt-invite`). В продукте заменить реальными фото впечатлений/мест. Иконок-ассетов нет — используются текстовые метки и символы (→, ✓, ✕, ●).

## Files
- `Ryk - прототип (3a).dc.html` — интерактивный прототип со всеми 16 экранами и доком. Открывается в браузере; левый навигатор служит для перехода между экранами при просмотре.
