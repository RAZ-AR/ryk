# Ryk v2 «Одна краска» — заметки к прототипу

Референс: Levanto (кремовая бумага, один ультрамарин, гротеск + курсивная антиква, моно-подписи).

## Идея

Всё приложение напечатано одной краской по бумаге. Чёрного нет, розового нет,
пастелей нет. Картинки карточек — растровый оттиск: те же семь фигур аур
(цветок, сердце, ореол, кольца, лучи, волна, свечение), но вместо размытого
цвета — сетка точек под 45°, точка тем крупнее, чем светлее место.

Запоминающийся ход — «Интересно»: точки набухают, и краска растекается по
фигуре, как штамп. Потом карточка уходит.

## Токены (кандидаты в `app/tokens.css`)

| Роль | Значение | Контраст |
|---|---|---|
| бумага | `#F3EDE3` | — |
| бумага поднятая (док, лист) | `#FBF8F2` | — |
| краска | `#1A3AD6` | 6.9:1 на бумаге |
| краска нажатая | `#142FB0` | 8.7:1 |
| вторичный текст | `#4458C2` | 5.3:1 |
| текст на краске | `#F3EDE3` / вторичный `#C7CDF0` | 6.9 / 5.1:1 |
| линии | краска 22 % | — |

Гарнитуры (все с кириллицей, через `next/font`):
- **Inter Tight** 500 — заголовки и интерфейс, трекинг −0.03…−0.055em;
- **Source Serif 4** italic 500 — вторая строка заголовка, «голос» карточки;
- **IBM Plex Mono** 500 — подписи капсом, +0.18em (уже в проекте).

Уходят: Prata, PT Serif, Caveat (рукописное заменяет курсив).

Радиусы: пилюля — действия и док, 24 — панель недели, 28 — лист. Тени нет —
вместо неё линия 1.5px краской.

## Что меняется в компонентах

- `AuraArt` → `PrintArt`: тот же `pickAura(seed)`, но SVG-растр одним `<path>`
  вместо фильтра размытия. Палитры `--aura-*`, `--foil-*`, `--cloud-field` уходят.
- `Ticket` упрощается: без перфорации, штрихкода, шахматки и орбиты.
  Оттиск → подпись моно → заголовок → курсив → спецификация → две пилюли.
- Неделя — негатив (краска с бумажными точками): самое важное на экране.
- Лист дня — без карточки: оттиск, «8 ноября. / Облачно.», реплика дня, спецификация.
- Док — бумажная пилюля с линией, активный пункт залит краской.

## Состояния в прототипе

Обложка, Сейчас, Хочу, Было; лента — карточки / загрузка / всё разобрано /
ошибка сохранения (карточка возвращается); неделя — выбрать / выбрана;
было — истории / пусто. На телефоне — через адрес: `?screen=was&was=empty`,
`?feed=loading`, `?open=night`.

## Не сделано

Колода «По одной», профиль, приглашения, чек-ин недели, экраны онбординга
после обложки. Английская и испанская версии текста не проверены на длину.
