# User Flows

## Flow A: Первый запуск

1. Пользователь видит обещание: «Одна история каждую неделю».
2. Выбирает интересующие категории.
3. Свайпает 15–20 конкретных идей.
4. Указывает бюджет и доступное время.
5. Выбирает социальный формат.
6. Указывает город и радиус.
7. Получает три первых предложения.
8. Выбирает первую историю недели.
9. Настраивает мягкие напоминания.

## Flow B: Добавление желания

1. Нажать «Добавить желание».
2. Ввести текст, голос или ссылку.
3. AI структурирует желание.
4. Пользователь подтверждает категорию, примерный бюджет и период.
5. Желание попадает в wishlist.
6. Система сообщает, когда появится хороший момент для реализации.

## Flow C: Выбор истории недели

1. В начале недели пользователь видит 3–5 карточек.
2. Каждая карточка содержит:
   - идею;
   - причину рекомендации;
   - цену;
   - длительность;
   - расстояние;
   - уровень новизны;
   - доступные даты.
3. Пользователь выбирает одну карточку.
4. При необходимости отвечает на один уточняющий вопрос.
5. Система формирует план.

## Flow D: Приглашение друга

1. Пользователь выбирает «Пойти с кем-то».
2. Ryk предлагает подходящих контактов или создаёт ссылку-приглашение.
3. Пользователь отправляет короткое сообщение.
4. Друг подтверждает или отклоняет.
5. При отказе система предлагает другого человека либо solo-версию.

## Flow E: Мягкая ответственность

1. Пользователь выбирает «Добавить свидетеля».
2. Друг получает только краткое обещание и дедлайн.
3. В конце недели друг видит «получилось» или «перенесено».
4. Нет публичных рейтингов и наказаний.

## Flow F: Срыв плана

1. Система замечает риск: нет билета, испортилась погода, пользователь откладывает.
2. AI спрашивает о барьере.
3. Предлагает:
   - упростить;
   - перенести в рамках недели;
   - заменить;
   - выполнить rescue mission.
4. Пользователь выбирает один вариант.
5. Неделя остаётся активной.

## Flow G: Завершение

1. После события приходит ненавязчивый check-in.
2. Пользователь нажимает «Сделано».
3. Выбирает эмоцию.
4. Добавляет фото или фразу.
5. Memory сохраняется.
6. AI задаёт только один полезный вопрос для улучшения рекомендаций.

## Flow H: «Выбери за меня»

1. Пользователь включает режим спонтанности.
2. Система выбирает один вариант из допустимого диапазона.
3. Показывает краткое объяснение и кнопку отказа.
4. После подтверждения начинается обычный weekly flow.

## Flow I: Пара

1. Два пользователя связывают профили.
2. Система находит пересечение интересов.
3. Раз в неделю предлагает 3 совместных идеи.
4. Каждый голосует независимо.
5. Выигрывает пересечение или компромиссный вариант.
6. Совместная история появляется у обоих.
