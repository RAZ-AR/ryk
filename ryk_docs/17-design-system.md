# Design System

> Единственный источник правды для визуального слоя Ryk. Когда код и этот файл
> расходятся — правим здесь (см. §11). Дополняет [14-brand-and-copy.md](14-brand-and-copy.md)
> (тон и тексты). Правила агента — в [`/CLAUDE.md`](../CLAUDE.md).
>
> **Статус значений:** палитра/тени/motion — заданы (черновик v0.1 по референсам,
> тюнингуется). Шрифты — ✅ приняты: Sora + Inter (§4).

## 0. Направление (из референсов)

Синтез двух источников:

- **Ощущение** — из [Unicorn neumorphic/flat UI](https://www.figma.com/design/iQCOh9pDaJ8QFvqIvTQbDK/): светлый фон, пастельные градиенты (мята → лаванда → розовый), **объём через мягкие цветные тени**, белые скруглённые карточки, плотные pill-кнопки.
- **Элементы/структура** — из [Sandow UI Kit](https://www.figma.com/design/SU5fL6KLWfb0ztZvTqAds4/): богатый набор компонентов и архетипов экранов (онбординг, AI-чат-компаньон, карточки, метрики, комьюнити). **Берём структуру, НЕ тёмно-оранжевый фитнес-вид.**

**Формула Ryk:** мягкий светлый «soft UI» с пастельными градиентами и объёмом (Unicorn) + продуманная компонентная структура (Sandow), адаптированные под спокойный, «человеческий» характер продукта.

> ⚠️ **Правило целостности (контраст vs нейморфизм).** Чистый нейморфизм проваливает
> WCAG (низкоконтрастный текст на пастели, «утопленные» элементы). Поэтому:
> **градиенты, пастель и объём — только для фонов, карточек и декоративных плиток;
> текст и действия остаются высококонтрастными** (тёмный текст на белом, один
> плотный CTA). Мягкость — в поверхностях и тенях, не в читаемости.

## 1. Atmosphere (характер в числах)

| Ось | 0 ← → 10 | Ryk |
|---|---|---|
| Плотность (воздушно ↔ плотно) | | **3** — много воздуха |
| Громкость (тихо ↔ ярко) | | **4** — спокойно; яркость в градиентах, не в UI-хроме |
| Motion (статично ↔ живо) | | **4** — мягкое, не игривое |
| Свет | | обе темы, **light по умолчанию** |
| Тепло (нейтрально ↔ тепло) | | **6** — тёплое, человеческое |
| Объём (плоско ↔ выпукло) | | **6** — мягкий soft-UI объём, без «пластилина» |

**Референсы (роли):**
- **Unicorn** — палитра, градиенты, мягкие цветные тени, форма карточек и кнопок.
- **Sandow** — таксономия экранов и полнота компонентов (особенно AI-companion chat, карточки, онбординг).

## 2. Anti-references (на что RYK НЕ должен быть похож)

- **Не productivity-дашборд / todo** — без плотных списков, чек-боксов, «инбоксов». Единица — история, не задача.
- **Не афиша / event-маркетплейс** — не сетка из десятков карточек-билетов. Показываем *мало* и объясняем «почему тебе».
- **Не тёмно-оранжевый фитнес-app (как сам Sandow)** — берём его структуру, не его агрессивный вид.
- **Не приторно-детский нейморфизм** — пастель и объём есть, но без «конфетной» игрушечности и низкого контраста.
- **Не соцсеть** — нет публичных лент со счётчиками лайков/подписчиков, нет сравнения жизней.
- **Не гейм-грайнд** — нет streaks, очков, бейджей, обратного отсчёта-давления.

## 3. Color

Закрытая палитра. **Hex живёт только здесь.** В коде — семантические токены. OKLCH-происхождение для предсказуемых light/dark; hex — производные (v0.1, тюнингуется по референсу).

**Правила:**
- **Градиенты «Aurora» — декоративны** (фоны, hero, плитки). Не под текстом, который должен читаться, без затемняющей подложки.
- **Один акцент действия на экран** (`brand.primary` или `action.ink`). Aurora — это атмосфера, НЕ акцент действия.
- Статусные цвета функциональны, не для декора. Статус дублируется иконкой/текстом (не только цветом).
- Никаких изобретённых на месте hex — новый оттенок сначала сюда.

| Токен | Hex | Роль |
|---|---|---|
| `aurora.mint` | `#A8E6D8` | старт сигнатурного градиента |
| `aurora.aqua` | `#A9D8F0` | голубой узел |
| `aurora.lavender` | `#C7B9F5` | середина градиента |
| `aurora.violet` | `#B0A0F0` | глубокий узел |

## 4. Typography

Эмфаза — масштабом или цветом, **не эскалацией веса**. Закрытый набор регистров. Шрифты подключаются локально (`next/font`), **покрытие latin + Cyrillic обязательно** (интерфейс en / ru / es).

✅ **Принято (2026-07-23):** Display/Heading — **Sora**, Body — **Inter**. Оба покрывают latin + Cyrillic, подключаются локально через `next/font`.

| Регистр | Size / LH | Weight | Tracking | Где |
|---|---|---|---|---|
| Display | 32 / 38 | 600 | −0.5 | обещание на первом экране, year review |
| Heading | 22 / 28 | 600 | −0.3 | заголовки экранов/карточек |
| Body | 16 / 24 | 400 | 0 | основной текст, чат компаньона |
| Body-strong | 16 / 24 | 600 | 0 | выделение внутри body |
| Caption | 13 / 18 | 500 | 0 | цена, расстояние, «почему это подходит» |

## 5. Spacing, radii, shadows

- **Отступы:** кратно **4pt** — `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`. Магических значений нет.
- **Радиусы:** `sm 10 · md 16 · lg 24 · xl 32 · pill 999`. Карточки — `lg`/`xl`. **Дочерний радиус ≤ родительского.**
- **Тени (soft UI):**
  - `shadow.soft` — `0 8px 24px rgba(24,26,44,.08)` (карточки).
  - `shadow.raised` — `0 16px 40px rgba(24,26,44,.12)` (модалки, шиты).
  - `shadow.tint` — цветной glow под декоративной плиткой: `0 12px 32px rgba(<aurora>, .35)`.
  - `shadow.inset` — нейморфный inset **только для декоративных контролов** (тогглы/слайдеры), никогда под текстом.

## 6. Motion

Числами. Каждая анимация — с фолбэком `prefers-reduced-motion`.

- **Длительности:** micro `120ms`, standard `200ms`, entrance `240ms`.
- **Easing:** `standard` = `cubic-bezier(0.22, 0.61, 0.36, 1)`. Spring — только для выбора карточки истории, с явными параметрами.
- **Запрещено:** `transition: all`; bounce на UI-хроме; `scale(0)→1` появления; параллакс-перегруз.
- Motion служит смыслу перехода (выбор → план → memory), а не «оживляжу».

## 8. Accessibility & inclusion

- **Контраст:** WCAG **AA** (текст ≥ 4.5:1, крупный ≥ 3:1) — в обеих темах. **Текст никогда не кладём на градиент без непрозрачной подложки** (см. §0).
- **Touch targets:** ≥ **44×44** pt.
- **Reduced motion:** каждая анимация имеет спокойный фолбэк.
- **Color-blind:** статус дублируется иконкой/текстом.
- **Языки:** en / ru / es — шрифты с latin + Cyrillic; проверять длину строк и переносы во всех трёх (ru/es длиннее en).
- **RTL:** **не требуется** — все три языка LTR. (Пересмотреть, если добавим арабский/иврит.)

## 9. Banned patterns (AI Slop Test)

Ловится дизайн-линтом по диффу. Тест: «поверит ли человек, что это сделал не generic-AI?»

**Общий slop:**
- gradient-**текст**; карточки по центру на радиальном «космосе»; «Welcome back! ✨»; стоковые «люди у ноутбуков»; `scale(0)→1`; `transition: all`.
- Сырой hex в компонентах; самопальные кнопки-`<span>`; call-site оверрайды примитивов; платформенные дефолты при своей системе.
- Эскалация веса шрифта вместо иерархии через масштаб/цвет/пространство.

**Специфично для нашего soft-UI:**
- **Низкоконтрастный нейморфный текст** (серый на пастели) — нарушение §0/§8.
- Текст поверх Aurora-градиента без подложки.
- Более одного акцента действия на экране; Aurora, используемая как акцент действия.
- «Пластилиновый» перебор объёма/glow.

**Специфично для Ryk (тёмные паттерны — запрещены):**
- Streak-счётчики, «не потеряй серию», обратный отсчёт-давление, красный «провалено» / язык вины ([07](07-ai-companion.md), [14](14-brand-and-copy.md)).
- Публичные счётчики популярности, рейтинги «кто живёт насыщеннее» ([08](08-social-and-accountability.md)).
- Спонсорское, замаскированное под органическое.

## 10. Design principles (фальсифицируемые)

1. **Один акцент — заслужи его.** Акцент действия только на главном действии экрана. Использован «для красоты» → удалить.
2. **Мягкость — в поверхностях, читаемость — в контрасте.** Текст на градиенте без подложки / серый нейморфный текст → баг (§0, §8).
3. **Иерархия — пространством, не весом.** Bold-эскалация ради акцента запрещена.
4. **Показываем мало.** Weekly Selection — 3–5 карточек, не сетка. >5 на экране выбора → баг.
5. **Каждая рекомендация объяснена.** У `StoryCard` всегда видима строка «почему это подходит». Нет строки → не готово.
6. **Ноль давления в пикселях.** Ни streak/отсчёта/«провалено». Найдено → удалить.
7. **Спокойное движение.** Нет анимации без `reduced-motion`-фолбэка и без смысла перехода.
