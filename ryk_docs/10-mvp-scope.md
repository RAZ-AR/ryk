# MVP Scope

## Цель MVP

Доказать, что пользователь готов каждую неделю выбирать одно впечатление, получать сопровождение и реально выполнять его чаще, чем без продукта.

## Формат

Предпочтительно:

- Telegram Mini App для быстрого теста; или
- лёгкое мобильное PWA.

Нативное приложение оправдано после подтверждения retention.

## MVP Features

### Обязательно

- регистрация;
- короткий онбординг;
- профиль интересов;
- ручной wishlist;
- генерация 3 идей на неделю;
- выбор Weekly Story;
- один базовый planning flow;
- контекстные напоминания;
- rescue mission;
- completion flow;
- архив воспоминаний;
- базовая аналитика.

### Можно вручную за кулисами

- подбор локальных событий;
- кураторская проверка рекомендаций;
- часть персонализации;
- партнёрские ссылки;
- сбор погоды и availability.

### Не включать

- публичную ленту;
- matching с незнакомцами;
- сложную геймификацию;
- полноценный маркетплейс;
- автоматические покупки;
- B2B-кабинет;
- сложную life analytics.

## MVP Weekly Flow

1. В понедельник пользователь получает три варианта.
2. Выбирает один.
3. Указывает примерный день.
4. Получает 1–3 полезных nudges.
5. При риске срыва получает альтернативу.
6. В конце отмечает результат.
7. Сохраняет одно фото или фразу.

## Concierge MVP

Для первых 50–100 пользователей часть работы можно делать вручную:

- куратор проверяет предложения;
- вручную ищутся билеты и места;
- AI генерирует сообщения на основе шаблонов;
- команда интервьюирует пользователей после каждой недели.

Это позволит изучить настоящие барьеры до автоматизации.

## Success Criteria

Через 8 недель пилота:

- не менее 60% активированных пользователей выбирают первую историю;
- не менее 35% выполняют первую историю;
- не менее 25% завершают историю в 4-й неделе;
- не менее 30% возвращаются на 6-й неделе;
- не менее 40% завершённых историй оцениваются как «без приложения, скорее всего, не сделал бы»;
- NPS среди активных пользователей выше 30.

## Pilot Market

Один город, 50–200 пользователей, ограниченный набор категорий:

- еда;
- культура;
- природа;
- спорт;
- встречи с людьми;
- маленькие открытия.
