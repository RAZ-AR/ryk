# Analytics and KPIs

## North Star Metric

**Meaningful Weeks:** количество недель, в которых пользователь подтвердил лично значимое реальное впечатление.

## Activation

Пользователь активирован, если в первые 48 часов он:

1. завершил онбординг;
2. выбрал первую Weekly Story;
3. совершил хотя бы одно planning action.

## Core Funnel

1. Recommendation viewed.
2. Weekly Story selected.
3. Commitment confirmed.
4. Planning action completed.
5. Experience started.
6. Experience completed.
7. Memory saved.
8. Next week returned.

## Основные KPI

### Engagement

- Weekly Selection Rate.
- Weekly Completion Rate.
- Rescue Success Rate.
- Memory Save Rate.
- Average Meaningful Weeks per active user.

### Retention

- W1, W4, W8 retention.
- Consecutive active weeks без обязательного streak-дизайна.
- Reactivation after missed week.

### Recommendation Quality

- acceptance rate;
- dismiss rate;
- save-for-later rate;
- completion by source;
- satisfaction after completion;
- «would not have done without Ryk» rate.

### Monetization

- booking conversion;
- commission per active user;
- free-to-premium conversion;
- premium retention;
- family plan adoption.

## Guardrail Metrics

- notification mute rate;
- uninstall after nudges;
- user-reported pressure;
- sponsored recommendation complaint rate;
- cancellation/refund rate;
- unsafe recommendation incidents;
- percentage недель, когда пользователь выбирает отдых.

## Qualitative Research

После завершения пилотной недели задавать один rotating question:

- «Что почти помешало?»
- «Почему выбрал именно это?»
- «Что приложение сделало полезного?»
- «Что выглядело навязчиво?»
- «Сделал бы это без Ryk?»

## Experiment Backlog

- три варианта против одного выбранного AI;
- понедельник против четверга как начало недели;
- witness против private commitment;
- functional push против emotional push;
- фиксированная категория против balanced portfolio;
- фото обязательное против опционального;
- weekly ritual против flexible cadence.
